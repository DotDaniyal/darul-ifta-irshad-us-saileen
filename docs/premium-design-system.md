# Premium Bilingual Design System

## Institutional character

The visual language combines **editorial scholarship** with **quiet Islamic geometry**. It uses warm ivory reading fields, deep-navy chambers, a single restrained green for interactive confirmation, and muted gold only for hierarchy, seals, and dividers. The fixed Urdu calligraphic masthead artwork remains a protected brand asset.

## Typography and direction

Urdu and Arabic content uses the established Noto Nastaliq Urdu / Noto Naskh Arabic stack with generous line-height and no clipping. English display copy uses Cormorant Garamond or DM Serif Display; Manrope serves controls, labels, metadata, and body copy. Urdu leads emotional and ceremonial hierarchy, while English provides concise supporting context. Directional layout adapts at the content level without disturbing the official three-part masthead lockup.

## Reusable grammar

| Element | Treatment |
| --- | --- |
| Reading field | Warm ivory, high contrast, subtle manuscript grain, generous measure |
| Scholarly chamber | Deep navy, low-contrast geometry, muted-gold divider or seal |
| Call to action | Navy primary, outlined secondary, restrained gold accent; clear focus and press feedback |
| Cards | Low-radius editorial panels with mihrab or folio framing only where it clarifies hierarchy |
| Motion | 160–750ms opacity/transform transitions, staggered by group, disabled under reduced motion |
| Navigation | Persistent but visually quieter after scroll, with native RTL/LTR-safe labels and active states |

## Interaction rules

The shared shell provides an unobtrusive reading-progress line, a back-to-top control after meaningful scroll depth, responsive mobile navigation with background-scroll lock, a short page-entry transition, and a compact header state. These enhancements must never delay content, hide essential controls, or change any Fatwa, translation, PDF, form, or administration workflow.
