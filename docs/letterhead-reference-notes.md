# Formal Letterhead Reference Notes

The supplied header reference uses a **very slim white institutional strip** with a fine dark lower rule. Its reading order is fixed from left to right regardless of Urdu content: a compact black English serif wordmark at left, a small central crest with a narrow ribbon, and an Urdu calligraphic identity at right.

The English and Urdu identity blocks both have compact dark capsule address labels beneath them. The typography is restrained, monochrome, letterpress-like, and tightly proportioned rather than large or high-contrast. The responsive adaptation should preserve this hierarchy while retaining the existing accessible site navigation below the letterhead.

## Arabic calligraphy implementation note

The current approved direction is a **Jali Thuluth-inspired** treatment for the selectable right-side Arabic institutional heading. Its visual colour is a single solid dark navy blue: `#0B2A4A`; it must not use gold, yellow, orange, gradients, metallic effects, or text shadows. The heading preserves the supplied Arabic wording and any source diacritics as authored, without synthetic repositioning or distortion. Katibeh is loaded from Google Fonts as the closest browser-deliverable, text-accessible calligraphic option; no exact licensed Jali Thuluth webfont was identified for direct deployment. The independent official logo is intentionally scaled up while retaining its accessible home-link semantics.
